# Отчёты УП06 — Вариант 11 (Цех корпусной мебели)

Структура и оформление соответствуют примерам из `!Готовые работы` (разделы 1–12).

## Как получить .docx

1. Выполните `git pull`
2. Откройте папку `TsehKorpusnoyMebeli\Отчеты`
3. Запустите **`restore_docx.bat`** (двойной щелчок)
4. Появятся файлы `00_…docx` … `12_…docx`

Исходники хранятся в `_b64_full\*.b64` (base64) — так GitHub принимает их без проблем с бинарниками.
